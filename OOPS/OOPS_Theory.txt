============Encapsulation===============
- Wrapping variables (data) + methods

While writing a class it should achieve encapsulation otherwise it wil become loose code.
Lets assume we have created a class with public data and some public method to modify the data but when another class using this class it can directly modify the data without implementing method 
so, this is not a proper way to modify the data , it should be modified through methods
Encapsulation says that nobody can change your data directly. Main purpose of encapsulation is to hide sensitive data or details while allowing the controlled access 

To achieve encapsulation follow below rules :
* Keep class data as private
* Keep methods public to modify data through it 


=============Inheritance===================
Inheritance is a key concept in OOPs where inheritance allows a class to use properties and methods of an another class.

Functionalities developed by parents class can be reused by child class.

           |-----IS-A relation
child ---->extends -----> parent
ex :
class parent{
}
class child extends parent{   // child have a properties of parent 
}
where child class can access all the attributes other than private and all the methods.

what is the purpose of inheritance ?
-- Inheritance allows to use the existing class instead of writing logics and everything from the scratch to while creating new class 

why do we need inheritance ?
-- code reusability this avoids code duplication and makes program more effiecient and easy maintainable , reduces time.
-- Method overriding - with the help of inheritance we can modify or extend the functionality of the parent class in th child class.

Terms used inheritance:
* super class (parent)
* sub class (child)
