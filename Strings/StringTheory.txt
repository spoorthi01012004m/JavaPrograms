============================================================String============================================================================

String --> String is a sequence of characters

Immutable --> once created you can not change it.
String object are immutable --> Once String object is created, you cannot change it. Even if you try to change it will create new object.

How to create String:
1. using literals --> String s = "";
2. using new  --->    String s = new String("");

-->If string created using literals object will be stored in a dedicated space inside heap memory.
  space is (String constant pool) scp . It was not there in earlier version of java. 
  
    why java go with this Literal approach ?
---->  For memory optimization using SCP

    Why Java made string immutable?
1. Memory Optimization
  
                Using Literals
				--------------
  Before creating new object using literals it checks whether is there any Object with same value already created, if object created earlier means it will new object start referring the earlier object value instead of created new one.
  
  ex: String first  = "Kodewala";
      *This object created inside SCP with address xyz123.
      String second = "Kodewala";
	  *THis checks is there any object created with same value , yes it is so , instead of created new object it refer the same address xyz123.
	  
	  To check address are same :
	  if(first == second) -->this will result true if address is same
	  
	 #in String '==' operator is used check the address of the string obj.
	 #obj1.equals(obj2) method belongs to String class which was overridden the Object class method.
	 
	            Using 'new' Keyword
				-------------------
  ex:  String firstname = "raj";  ---> raj is literal
       String secondName = new String("raj"); raj is also literal 
	   When the object of String created using new keyword a copy of the value will be stored in SCP but object is created inside the heap area.
	   In the above example even both content is same new secondName object will be created in heap memory because of new keyword.
	 #in String '==' operator is used check the address of the string obj.
	 #obj1.equals(obj2) method belongs to String class which was overridden the Object class method.
	 

Some rules in strings to remeber:
---------------------------------
1. String s = "practice" --> this is created using literal and only one object will be stored in SCP.
2. String s = new String("practice") --> This is using 'new' keyword , 'practice' is literal so 1 obj is creats in SCP but new keyword creates new obj and store it in heap ,now s is reference heap obj.
3. String s = "Hello" + "World" --> when 2 words are literal with + symbol then it will become one obj by combining "Helloworld".
4. String s1 = "practice" --> s.equals(s1) -->this checks the content of the objects if both are same, returns true.
5. s == s1 --> this checks references, if both are referring same then returns true, else false
6. In SCP before creating obj it checks, whether is there any obj with the same content or not, if so it start referring the existing one instead of creating new one.
7. String obj created using new keyword , always creates new obj even if any objects exists with same content.

=====================================StringBuilder================================

-- When string need to modify the content , not possible with strings so,
  This can be done by using StringBuilder and StringBuffer
  
to use StringBuilder :
StringBuilder sb  = new StringBuilder("");

Key Features of StringBuilder:

* Strings are mutable
* No thread safety , not have overhead of synchronised method
* Performance is faster
* Suitable for single threaded usage
